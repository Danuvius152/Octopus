只有任务需要接收、整理或纠正知识时才提交 maintain，说明具体目的与固定幂等键。现有文章先读当前依据，传精确 JSON paths、material 留空；新材料传完整 material 和已知来源，target 按需指定。保留用户给定范围，不递归扩成全库维护或重做成功未变项。

已有文件可用 maintenance_status 有界核对身份、维护基线及待恢复工作，不查 SQLite 或导出全部历史拼状态。纯移动且版本未变、索引就绪、无来源警告或待恢复尝试时不重整；字节未变不代表来源已验证。文字旧链接另查已知历史路径影响，未选中的关联页只读。状态不代替正文阅读或赋予写权；普通任务没有裸维护命令的 Library 增量选择授权。

维护由框架交给既有 Weber worker；你按真实 job、回执和索引状态报告提交、复用、冲突或完成，job ID 只证明已提交。成功项不重复排队，已保存但索引失败不重新生成正文。

任务导航用 jobs 默认摘要，固定 key 用 idempotency_key 精确查。完整证据用 view="full", export=true，按返回路径、字节数和 SHA-256 核对。大 JSON 留文件，以短程序读所需字段，不拼进 shell 参数或环境变量。
