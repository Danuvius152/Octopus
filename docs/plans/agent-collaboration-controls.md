# Agent 协作许可与人工控制

> **Status:** proposed — 调用许可、进度展示与人工接管的待决范围。

命名委派按同账户与目标生命周期校验；当前没有产品级 Agent allow/deny 矩阵。原生子任务可观察，不等于具备独立会话或完整人工控制。

待决范围：选择需要限制的调用关系，或需要接管的原工作身份；许可默认值、问题接管和 provider 控制能力须随该需求确认。

当前合同：[领域说明](../implemented/agent-collaboration.md)。本条记录需求边界，不预选实现方案，
也不构成开工、发布或数据操作授权。具体设计由获授权的活动任务规格维护。

## 当前票的补充指令与复审回传

该项暂缓。主轮结束后仍在等待当票复审时，用户补充「验收好后停止，不启动 06 票」一类限制，会被接纳为独立请求。原批次授权校验随后关闭自动回传，主会话需要从子会话取回复审结果才能完成验收。[当前回传规则](../implemented/input-reliability.md#ticket-handoffs)

用户应能在主轮结束后明确为当前票补充范围限制。复审回传按新限制继续当票验收，「验收后停止」使批次在当票验收后结束。显式 Stop、替换原任务或已生效的票间交接应关闭对应的旧回传。
