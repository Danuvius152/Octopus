# 通用资源 CLI 缺口

> **Status:** proposed — 当前 octopus CLI 尚不是通用 octo 资源管理接口。

现有 octopus 命令覆盖服务/安装、会话交接拉取、监控与账户搬迁。底层 token issue/list/revoke 方法不等于完整的用户凭据管理界面。

待决范围：选择真实脚本或应用消费者，明确资源操作及账户权限；命名、API 版本和分发方式尚未选定。

当前合同：[领域说明](../implemented/multi-tenancy.md)。本条记录需求边界，不预选实现方案，
也不构成开工、发布或数据操作授权。具体设计由获授权的活动任务规格维护。
