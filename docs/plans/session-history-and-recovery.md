# 会话分支与文件还原边界

> **Status:** proposed — 同路径文件归因和外部效果恢复的缺口。

safe-revert 检查捕获的 Git 状态、ignored 基线、index、HEAD 和路径；没有任意同路径人工修改的逐字归因，也不撤销外部副作用。Git 辅助进程的取消/超时退出确认仍有限制。

待决范围：选择需要增强的恢复场景和真实文件证据；不得把保守拒绝改写为任意人工修改均可安全还原。

当前合同：[领域说明](../implemented/session-rewind.md)。本条记录需求边界，不预选实现方案，
也不构成开工、发布或数据操作授权。具体设计由获授权的活动任务规格维护。
