# 聊天文件链接与预览

> **Status:** paused — 聊天文件链接与 `/showme` 共用预览和行号定位。

聊天回复中的本地文件路径按普通 Markdown 链接渲染，样式难以与正文区分。点击指向 `agent-collaboration-controls.md:12` 的绝对路径时，浏览器把服务器文件路径当作网页地址，请求返回 404。`/showme` 已提供按会话工作目录授权的文件查看器。 [文件查看意图](../implemented/frontend-interaction-state.md#文件查看意图)

- 聊天中的文件链接应当清楚可辨，支持点击和键盘打开。明确路径的链接和 `/showme` 共用文件查看器及读取入口，直接解析路径和可选行号。带行号的 Markdown、代码或纯文本预览定位到对应内容。验收覆盖已有回复中的链接、带空格或中文的路径和普通网页链接的导航。
- 文件读取按引用所属的会话及已授权来源校验路径、类型和大小。验收覆盖工作目录内的文件，以及账户 workspace 会话里引用的仓库计划。目录外的交付物由明确授权的来源提供预览，权限不足、文件缺失或行号失效时在会话内说明原因。
