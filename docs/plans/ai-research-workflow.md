## A：研究问点和完整证据

先从原请求保留“问点—所需证据—交付要求”，再生成搜索角度。搜索没找到的问点
仍在最终覆盖表中，分清找不到、未读、访问失败、存在争议与不适用。用户改变
问题时记实际变化，不以搜索结果反向缩减原需求。

每条会改变判断的结论按需要关联以下概念，实施前复用现有术语而不创建同义对象：

| 信息 | 最少保留内容 |
| --- | --- |
| 来源 | 稳定身份、URL/真实本地身份、版本/访问时间、实际读取位置、摘录与访问/提取限制。 |
| 结论 | 表述、提出者、适用条件、支持/反对材料、尚缺什么。 |
| 核验 | 对象、方法、位置、理由与局限；来源独立性不明时保留未知。 |
| 覆盖 | 原问点、证据要求、当前状态与相关结论，不随 leaf 失败消失。 |
| 实验 | 实际设置、运行尝试、执行状态和结果位置；未运行不生成成功记录。 |

支持、反对、争议和缺口都进入证据结构与适当报告位置。被否定的条目不作正向
推荐，仍保留“原主张—反证—条件—当前处理”，方便下一次研究。作者主张、来源
支持、本地复现与本次推断分别表达，不能压成一个递增的 verified 等级。

比较指标绑定同一实验对象的配置、单位、统计口径与表行/输出位置。数据划分、
身份是否见过、输入模态/长度、分辨率、时序窗口、硬件、精度、batch、缓存/预热、
测量起止点与端到端/单模块范围按问题选择。不同配置的质量和速度不能拼成一个
“同时最优”的对象；候选覆盖有限时结论也限定于已检查候选。

报告保留可读正文和绑定的结构化证据，沿现有有界摘要扩展，不增加另一套质量结论。
模型填了 URL 不证明已
读取；能取得读取证据时关联真实返回，否则保留核验限制并对关键结论回原文。
证据充分性是内容事实，不挪用原任务成功/通知/退休状态。

## P：PDF 材料准备、阅读与成文

转换属于 Wiki 外的材料准备。保留只读原件，检查逐页文本层与阅读顺序，再对
需要的页面 OCR/视觉核读。现有参考包的 `pdftotext`/OCR 观察不证明完整 PDF→MD
能力；转换器按代表性材料的真实结果选择，不在本计划认证某个默认产品。

一次选定的转换完整交付以下行为：

1. 识别原件与版本、约定范围和重复请求，逐页记录已转换、已核对及不可读状态。
2. 保留正文顺序、章节、脚注、引用及必要图表。关键表格保持行列、单位、脚注和
   比较条件；不可靠的文字、数字、公式保留原页/原图与待核标记。
3. 将 Markdown 的段落、表、图关联到真实页码和必要区域，分开物理页与印刷页。
   转换成功、视觉核对和语义阅读分别记录，流畅文字不能掩盖错序/OCR 缺口。
4. Markdown、资源和映射在任务目录成组交付；从最终读者入口重开关键图表和
   附件。需要离线/搬迁时再验证相应完整性，不只检查 hash 或文件数量。
5. 再转换不覆盖人工笔记；原件更新产生新版本映射。任务包含入库时经现有获准
   Markdown 维护入口交接，文件生成、任务接管、发布和索引完成分别取证。

转换稿保存原文与识别缺口；阅读笔记保存作者问题/方法/证据及明确标出的分析；
综合写作围绕当前问题组织关系与分歧。三种用途不要求每篇都产三份文件。
局部问题读到证据充分；整篇总结/评价覆盖同版本全文，缺失图表/附录如实披露。
关键数字或版式歧义回原页核读，只有图注时不宣称分析过图中内容。

写作先保护数字、单位、否定、比较方向、因果、归属与判断强度，再按体裁组织
段落并连续复读。检查“may→必然”“作者报告→独立证实”等越界；参考工具的
作者画像不成为用户画像。引用贴近所支持的句子，提取疑点不靠润色填补。

## B：已有知识与研究、Wiki 的交接

主会话需要既有知识时按当前授权查询，向研究传递有界的已读上下文：原问题、
资料身份/版本、实际摘录、适用结论与待核问题。简单问题可以直接完成，明确
要求联网的部分仍核当前来源。内部路径与私人内容不直接变成公开搜索词。

web leaf 继续不继承 Wiki、memory 或 MCP；入口和数据流需要真正接通，prompt
中写“去查 Wiki”不能伪造工具能力。没有本地上下文时明确本次只调查外部资料。
研究结果交给受控维护时包含准确目标、来源、版本、结论状态与具体保留项，沿
现有 worker 流程取得真实回执，不新增 Markdown 写旁路，也不把 job id 当完成。

Wiki 拥有长期解释/综合，任务目录拥有报告与证据包，实验项目拥有代码/数据引用/
输出，memory 只存工作约定和入口。新证据指明改变了哪个版本的哪项主张，检查
实际受影响推理；主题相近与因果依赖分开，失败也不自动反驳方法。

## 可观察预算、跨 job 缓存与检查点

这些是可分别选择的后续增量，复用现有 orchestrator/leaf 和原任务身份：

| 增量 | 启动条件与完成条件 |
| --- | --- |
| 每 job 工作预算 | 有成本/时限需求时，展示选定角度、leaf/核验上限、已耗与剩余；取消/失败成本保留。预算耗尽交付明确缺口，有限 leaf 重试只处理已知安全失败，不能无限扩搜。 |
| 跨 job 来源/结果缓存 | 有实际重复读取成本时，以账户权限、来源版本、问题/配置和读取范围绑定；撤权不继续返回私料，过期与提取失败分开。失效能重取且不把缓存命中当本轮已核全文。 |
| 已完成阶段检查点 | 持久化足以复用的输入、配置、阶段结果与原 work 身份；恢复先核版本和原尝试状态，不能重跑未知外部效果。晚到旧尝试不能覆盖新结果，取消与资源退休分开。 |
| 非文本证据 | 从 P 的真实缺口扩展图片、表格、视频时间段与补充材料；保留可重开定位、读取覆盖与理解限制，静态预览不冒充完整时序理解。 |

预算只在 usage 可观测时承诺对应成本：未知 USD 不是零，取不到完整用量时只
声明可证明的次数/时间上限。read-only leaf 有限重试先确认原资源退休，父会话
回交未知不触发 pipeline 重跑。缓存键含规范化查询/来源、获取时间、backend/
model/version 和账户 scope，提供强制刷新与时效 TTL；缓存投票不能冒充新 job
的独立验证。检查点只复用完整阶段结果，未确认 leaf 明确放弃或在退休后重跑。

新增持久类型、关系与根同步定义[账户搬迁](../backup-and-migrate.md#account-export-and-import)
收集/排除/恢复和[数据保留](data-retention.md)。大文件可有可靠外部引用，但注明
可取得性与缺口，导出账户成功不代表外部权重/数据已可离线复现。

## 单机实验、续接与条件扩展

先围绕一个真实单机实验绑定假设、代码及未提交改动、数据划分、模型/权重、
配置/随机种子、指标、环境与预算。实验设定与各次运行尝试分开；改变设定形成
新实验，checkpoint 恢复也不冒充算法加速。执行成功、必要产物齐备、核验通过
分别确认，退出码零或 hash 一致不能代替语义核验。

结果和有信息量的失败保存在可定位位置：方法/实现/环境/资源/评测问题分开，
说明尚不能排除什么及什么变化值得重试。完整结果与本次有界返回分开，超限、
丢回执或等待超时沿原身份取回，不重新计算；概览、增量与定向详情各有范围。

多节点只在真实异构资源、长任务或远程恢复需求下接项目适配器。原 attempt 的
停止与资源释放分别证明，心跳/lease 过期不等于进程死去，未知仍保留占用和
已耗成本。数据就地处理，临时节点回收前保存必要证据。程序监测与 AI 判断
分开，候补必须已有获准输入/代码/核验/预算；无有用工作时允许空闲，不为满载
扩大研究范围。该扩展与[Runtime provider](runtime-providers.md)的真实环境能力对齐。

辅助学习仅在用户要练习理解/研究时启用，沿用户路线指出缺口，区分本人和助手
贡献，以能解释条件、诊断新例衡量掌握。正常实现/实验/综述请求继续交付，不
强制变成教学，不迁移数学题准入、固定拒答或训练管理员权限体系。

## 完成条件与验证

A 要验证原问点不消失、反证/理由保留、指标条件不串配置、同源不冒充独立、搜索
全失败仍诚实报告缺口。P 要覆盖双栏、扫描/混合页、复杂表格、图像和部分失败/
重复转换/原件更新，并用产物回答一个真实问题。B 用“旧知识＋新证据＋明确
结论”走完整交接；续接用连续任务验证新证据改变的具体判断与旧失败复用。

实验扩展至少覆盖：退出码零但漏样本/缺产物、提交后丢回执、响应超限、取消/
断连/旧尝试迟到、代码/数据版本变化和导出后依赖缺失。先从最容易否定设计的
场景开始，确定性小作业验证功能；内容质量继续 opt-in `knowledge_eval`。

冻结开发材料与保留验收材料，区分读过的支持、来源不足、语义错误和访问失败。
记录质量、墙钟时间、调用/token、重复读取、失败重试及冷读/复用差异；并行耗时
不相加冒充墙钟时间。不得有伪造来源、虚假复现、越权写库和无条件错误排名。
适用检查与证据复用归[testing.md](../testing.md)，不另建评测平台或常规付费门禁。
