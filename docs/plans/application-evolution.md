## SmartReader 阅读上下文覆盖

SmartReader 把网页提取出的文本随对话请求传给 Agent。`content.isPartial`
反映文本是否超出发送预算，或上游是否已标记为部分文本。网页提取可以漏掉
侧栏和配图，即使该字段为 `false`，Agent 仍可能只收到部分来源内容。

待决需求是让 Agent 知道收到的材料覆盖了什么。用户询问整篇原文时，Agent
应能在有来源且具备访问条件时查阅原文，据实际读到的内容说明覆盖范围。原文
不可访问时，可依据已有材料作答，并明确交代缺失的部分或覆盖范围未知。

验收应覆盖提取文本未超限但遗漏侧栏或配图、文本因预算被截取，以及原文无法
取得的情况。仅收到提取文本时，回答应准确说明所读材料的范围。
