# 运行活动独立于显示文本

Codex 0.162.1 会从 exec JSON 输出省略无摘要推理，仅用可显示事件驱动静默计时会中断仍在执行的轮次。用户 Q17 确认真实活动也刷新静默计时，因此 Octopus 的 Harness 负责独立活动信号和当前尝试/原生轮次归属，展示、存储及网络等待不承担活动计时；代价是需要约束原生活动格式和观察者生命周期，但不修改 Codex 或放宽既有超时与恢复策略。

实施与验证边界见[运行时接口修补方案](../plans/runtime-interface-repair.md#81-r01harness-拥有独立活动通道)。
