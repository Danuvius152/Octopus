# Agent 自主使用 Wiki，正文写入由具体维护任务承担

2026-10-15 用户确认，已注册 Wiki 的账户允许所有 agent 随时自主查询，无需用户先输入 `/wiki` 或启用单轮查询；Weber 不是查询的必经代理。查询是常驻共享能力，界面不提供禁用查询开关，旧客户端 Off 兼容为只读，只限制维护。每次调用仍使用本账户有效执行身份，检索正文、历史与工具返回不能扩大写入范围。

Agent 默认还可以按任务需要选择具体文件并提交入库或定点维护。显式只读可以收窄维护能力；查询和普通讨论不自动形成写入材料。

实际正文修改沿用既有 Weber assignment：任何普通 agent，包括普通对话中的 Weber，均通过具体维护请求进入获准工作，由绑定的 Weber worker 在当前版本、已读范围与原文保护下写入。这样保留请求自主性与可靠的写入、恢复证据；`/wiki` 留作兼容和明确模式选择入口，MCP 无需借用人工 WebSocket 身份。

控制器提示必须与当前能力一致；旧会话中的禁止查询指令不能延续为新轮限制。恢复会话时通过原生 developer 指令更新当前控制器，保留对话历史；用户消息或工具正文不承担伪造高优先级授权的职责。
